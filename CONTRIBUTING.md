# Contribution à LayeForge

Merci de l'intérêt que vous portez à LayeForge ! Nous sommes ravis d'accueillir vos contributions pour faire de ce projet le meilleur générateur d'applications desktop au monde.

## Comment contribuer ?

### 1. Rapporter des Bugs
Si vous trouvez un bug, veuillez ouvrir une "Issue" sur GitHub en précisant :
- Votre version de Windows.
- Les étapes pour reproduire le problème.
- Le comportement attendu vs le comportement observé.

### 2. Proposer des Fonctionnalités
Les idées sont les bienvenues ! Ouvrez une "Issue" avec le label `enhancement` pour discuter de votre proposition.

### 3. Soumettre des Modifications (Pull Requests)
- Clonez le dépôt.
- Créez une branche pour votre modification (`git checkout -b feature/ma-fonctionnalite`).
- Assurez-vous que votre code respecte le style du projet.
- Soumettez votre Pull Request avec une description claire des changements.

## Configuration Locale

Pour travailler sur le code :
1. `npm install`
2. `npm run setup-env`
3. `npm start`
