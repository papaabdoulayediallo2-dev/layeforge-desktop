# Support LayeForge

Si vous rencontrez des difficultés avec LayeForge, voici les différentes manières d'obtenir de l'aide :

## 1. Documentation
Consultez le [README.md](README.md) pour les guides de démarrage rapide et les détails techniques.

## 2. GitHub Issues
Recherchez parmi les [Issues existantes](https://github.com/papaabdoulayediallo2-dev/layeforge-desktop/issues) pour voir si votre problème a déjà été résolu. Si ce n'est pas le cas, ouvrez une nouvelle issue.

## 3. Discussions GitHub
Pour les questions générales, les conseils d'utilisation ou pour partager vos créations, utilisez l'onglet **Discussions** de notre dépôt GitHub.

## 4. Contact Direct
Pour des questions de sécurité ou des demandes spécifiques, vous pouvez contacter l'auteur via GitHub.

---
*LayeForge est un projet gratuit. Le support est fourni par la communauté au mieux de ses capacités.*
